Qué ocurre cuando escribo una URL

Cuando escribo una URL en el navegador, comienza un proceso que permite localizar el servidor donde se encuentra la página y solicitarle sus recursos.

  1. Escribo una URL en la barra de direcciones del navegador.
  2. El navegador identifica el dominio de la página que quiero visitar.
  3. Se utiliza el sistema DNS para obtener la dirección IP asociada al dominio.
  4. El navegador establece una comunicación con el servidor.
  5. El servidor recibe la petición y responde con los recursos necesarios.
  6. El navegador recibe el HTML y otros recursos, como CSS, JavaScript o imágenes.
  7. Finalmente, el navegador interpreta esos recursos y muestra la página en pantalla.

Herramientas que utilizo

Visual Studio Code

Utilizo Visual Studio Code como editor para escribir y organizar los archivos de mis proyectos.

Extensiones

Las extensiones permiten añadir funciones al editor y facilitan algunas tareas durante el desarrollo.

  • Extensiones para trabajar con HTML.
  • Extensiones para mejorar la edición del código.
  • Extensiones para facilitar el desarrollo.

Live Server

Live Server permite abrir el proyecto en un navegador mediante un servidor local y comprobar los cambios.

Git

Git es un sistema de control de versiones que permite registrar los cambios de un proyecto y consultar su historial.

GitHub

GitHub permite almacenar repositorios Git en Internet y compartir proyectos con otras personas.

Estructura de carpetas

La estructura básica de mi portfolio es la siguiente:

portfolio/
├── index.html
├── entorno.html
├── sobre-mi.html
├── proyectos.html
├── README.md
├── docs/
│   └── presentacion.txt
└── img/
    ├── avatar-tostada.png
    └── proyectos/

Organización del proyecto

El archivo index.html funciona como portada del portfolio. El archivo entorno.html contiene información sobre mi entorno de trabajo. En sobre-mi.html cuento quién soy y en proyectos.html muestro mis trabajos.

La carpeta img almacena las imágenes que utiliza el portfolio y la carpeta docs, los documentos descargables. El archivo README.md contiene información general del proyecto.
